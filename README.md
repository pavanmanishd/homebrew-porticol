# Porticol for Homebrew

    brew install --cask pavanmanishd/porticol/porticol
    brew install pavanmanishd/porticol/porticol-cli

The cask installs the Porticol desktop app and the formula installs `porticol-cli`, both from https://updates.porticol.app. The command line is open source at https://github.com/pavanmanishd/porticol-cli. See https://porticol.app.
